# 第二轮：扩充数据、固定深度、初始化与损失对照

这轮针对第一轮泛化失败，先盘点本机整包SFishTrack，不要求下载UVID。54段视频有24,115张RGB图、23,532帧标注；压缩包约27.49GB，其中Frames约26.39GB、Videos约1.00GB。大体积主要来自逐帧图片，不能理解成54个独立拍摄来源。

## 数据与冻结顺序

源包、旧全包JSON审计及元数据均保持原样。`audit_corpus.py`读取ZIP目录和每段首/中/末三张图，不重复全27GB SHA或全CRC扫描。部分片段高度相似或带旋转/黑边，049/050的选中窗口有大量完全重复RGB。旧日期分组与包内统一元数据冲突，原始拍摄来源独立性仍未证实。

训练覆盖SFishTrack的49个视频文件，排除007、012、025、026、027。012沿用无效日期隔离；007/025保留为旧回归；026与025属于同一保守来源组，作留出诊断，不称全新独立来源测试；027不足64个连续RGB且有历史评价记录，本轮不追加。其余每段在最长连续RGB区间取居中64帧，规则不使用目标数量、模型评分或输出质量。候选训练P帧为3,087。

UV-Multi video96的前128帧用于唯一选模验证，video108前128帧作本轮最终序列留出。它们来自本机已有旧数据，不下载。注意发布者压缩包名可能与实际目录名不同，本轮按此前审计后的实际video ID及逐帧像素SHA读取。两段曾用于旧项目，且缺原始拍摄标识，不能称从未使用或拍摄来源完全独立。

source.npy、真实码流、接收端latent及教师RGB完整校验后，`freeze_samples.py`仅在训练集内按“latent输入＋原图RGB＋教师RGB”三个哈希联合去除完全重复监督。先冻结实际训练pair清单，再启动任何优化器更新。原图相同而码流上下文不同的样本不被误删。验证与最终留出间的完全相同RGB会拒绝准备；旧回归片单独标明相关性。

RGB统一Lanczos到512×288，原规则填充512×320；q12、GOP64、reset32。仅使用发布帧顺序，不声称原始拍摄时间轴已全部验证；不据名义30fps计算真实码率。两个UV序列只有稀疏鱼体GT，必须通过gt_available门控；未标注帧不是全背景。UV鱼类发布色为RGB(0,0,128)，重新核对发布掩码哈希及既有二值鱼体掩码。SF26的可用RLE并集与发布掩码核对后才用于区域评价。

## 学生及初始化

学生base width64，每级3个残差块，10,985,155参数。教师base width128，每级3块，42,515,587参数。保留层级与模块顺序，不同时缩减深度，I帧、原压缩链及潜变量参考链仍保持教师。

迁移为明确的近似初始化基线：在每个教师GroupNorm组内保留一半通道，按同宽度层的平均绝对gamma排序，稳定处理并列；相同特征宽度使用一致的通道映射，残差分支、卷积输入/输出、注意力Q/K/V及投影同步映射。256通道latent接口、post_quant_conv和3通道RGB接口完整保留。所有学生状态张量都被映射，没有遗漏的随机层，不使用验证/测试画面或分数确定通道。

这不是功能保持裁剪。删去卷积输入、改变组内归一化统计及注意力通道维数都会改变函数，不能保证迁移初始画质接近教师。`model_transfer.py`检查同宽度迁移的状态哈希完全相同，并用历史P帧核对原教师GPU输出与缓存逐字节一致。临时副本执行一次真实AdamW更新检查有限梯度和显存，随后丢弃；四组正式训练仍从未改变的初始化文件开始。

## 四组同预算对照

| case | 初始化 | 损失 |
|---|---|---|
| random_mixed | 固定随机初始化 | 0.5 L1(S,T) + 0.5 L1(S,G) |
| mapped_mixed | 教师近似迁移 | 同上 |
| mapped_teacher | 相同教师迁移 | L1(S,T) |
| mapped_gt | 相同教师迁移 | L1(S,G) |

四组各5000个真实非零学习率更新，相同pair清单、抽样索引、batch1、AdamW、梯度范数裁剪1。前100步预热到1e-4，之后余弦降至1e-5；FP32参数、BF16训练、FP32验证，TF32关闭。第0步及每500步按UV96所有P帧对原图的聚合MSE选最佳检查点，包含初始基线以免训练损坏时丢掉更好的初始权重；再按相同指标在四个case间选出候选，最后才看最终留出与旧回归结果。不加入VGG、感知、特征或时序损失，不下载权重。

random_mixed与mapped_mixed隔离初始化差异；三个mapped case隔离损失差异。与首轮相比同时改变数据和深度，因此不能把跨轮改善单独归因于某一个因素。每组只有一个种子，不能声称统计显著优势。

## 本机命令

已有结果直接阅读，不需重跑。新运行用不存在的新目录；先创建根目录，再依次执行下列命令。沿用现有环境，无系统安装。

~~~powershell
$r2Root = 'C:/Users/lenovo/Documents/ChatGPT/语义通信/01_项目/代码/semantic_video_test/12_优化阶段_GLC蒸馏'
$r2Output = 'C:/Users/lenovo/Documents/ChatGPT/语义通信/02_实验数据/优化_GLC蒸馏/新的第二轮目录'
$r2Gpu = 'C:/Users/lenovo/Desktop/works/work/semantic-video-training/.venv-glc/Scripts/python.exe'
$r2Cpu = 'C:/Users/lenovo/Desktop/works/work/semantic-video-mlvc/.venv/Scripts/python.exe'
$env:PYTHONIOENCODING = 'utf-8'
New-Item -ItemType Directory -Path $r2Output -ErrorAction Stop
& $r2Cpu -B "$r2Root/round2/audit_corpus.py" --output "$r2Output/sfish_audit"
if ($LASTEXITCODE -ne 0) { throw 'source audit failed' }
& $r2Cpu -B "$r2Root/round2/prepare_round2.py" --output $r2Output
if ($LASTEXITCODE -ne 0) { throw 'data preparation failed' }
& $r2Gpu -B "$r2Root/round2/model_transfer.py" --output $r2Output
if ($LASTEXITCODE -ne 0) { throw 'initialization audit failed' }
& $r2Gpu -B "$r2Root/cache_pilot.py" --output $r2Output --role encode
if ($LASTEXITCODE -ne 0) { throw 'stream encoding failed' }
& $r2Gpu -B "$r2Root/cache_pilot.py" --output $r2Output --role decode
if ($LASTEXITCODE -ne 0) { throw 'independent decode/replay failed' }
& $r2Gpu -B "$r2Root/round2/run_round2.py" --output $r2Output --phase train
if ($LASTEXITCODE -ne 0) { throw 'paired training failed' }
& $r2Gpu -B "$r2Root/round2/run_round2.py" --output $r2Output --phase evaluate --plot-python $r2Cpu
~~~

在根目录创建STOP文件可请求本轮保存并停止；恢复前删除STOP，对未完成case用 `train_round2.py --case <case> --resume`。已完成case不会重跑。独立评价拒绝覆盖已有结果；出错时保留诊断，检查后明确继续，不从最终结果反向调参。

独立学生解码器禁止读取源图、掩码、缓存latent和缓存教师。全文件载荷SHA、原逐帧参考链、有序latent及I帧RGB校验保留，P帧学生RGB使用明确模型ID和新输出校验。完整解码质量须复现选模时缓存验证的MSE。

完整评价后，可运行 `diagnose_color_error.py --output <结果目录>` 生成事后颜色误差分解；已有分解用 `--verify` 复现核对。该工具读取原图只作诊断，不生成颜色修正重建，不改权重或重新选模。

速度只测按UV96选出的候选与原教师，同一128帧码流，三组交替顺序连续配对，各新进程预热I/P两帧，FP32/TF32关闭，保留全部慢步骤。质量生成的trial0不混入速度配对。计时不含模型加载、磁盘I/O、MP4编码和网络，仍不能写成整个通信系统或Orin的加速。
