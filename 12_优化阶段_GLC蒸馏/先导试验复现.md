# 真实蒸馏先导试验

本轮仅训练 P 帧最终 RGB 生成器（8,800,707 参数），I 帧仍用原教师。原始 z/y 码流、熵模型、潜变量网络和 `ref_latent/ref_y` 参考链均保持原样。不是完整 GLC 的重新训练。

## 固定范围

- 本机已有 SFishTrack ZIP，训练视频001–006各64帧，共378个P帧；验证007共96帧，其中94个P帧；静态测试025共64帧，其中63个P帧。
- 训练片属于既有保守分组，画面高度相似。原始拍摄来源独立性尚未成立；007/025是序列留出，不能称全新独立来源基准。
- q12，512×288，右下按原规则复制填充至512×320，GOP64，reset32。只有这一码率档和尺寸进入本轮训练。
- 007的扩展96帧有95帧通过既有严格时间唯一匹配，1帧未达唯一性门槛。96帧保留用于逐帧画质及GOP边界观察，预览按帧序30fps播放；不作96帧已验证时序或码率结论。原有前64帧已有独立时序审计。
- 025有真实可变PTS，仅做静态画质比较，不人为按固定帧率补出时序结论。

## 训练与对照

两个模型都从同一随机初始化开始，使用相同抽样顺序、AdamW、学习率计划、5000个真实更新步。每步完整512×288有效画面、batch1，FP32参数配合BF16训练，FP32验证。前100步预热至1e-4，余下余弦降至1e-5，梯度范数裁剪1。

KD组：`0.5 × L1(学生, 教师uint8输出) + 0.5 × L1(学生, 原图)`。GT组：只用 `L1(学生, 原图)`。RGB损失空间为[-1,1]。不使用感知或时序损失，不下载VGG/LPIPS权重。

每500步对007的所有P帧进行FP32验证，按对原图MSE最小选检查点。025不参与训练或选模。每组保留初始、最佳和末次含优化器状态的检查点，并另导出只含学生模型的推理权重。首轮有限数据与5000步不足以保证可部署画质。

## 缓存与解码校验

`prepare_pilot.py`在CPU环境只读取已有ZIP成员，以CRC、逐帧SHA及既有清单核对来源；验证/测试鱼体掩码从RLE并集生成并与发布者掩码逐像素核对，再最近邻缩小。

`cache_pilot.py --role encode`经真实字节流路径编码。新进程 `--role decode`禁用所有源帧编码器，审计钩子禁止读取原图、GT掩码和时序匹配图片。接收端逐帧核对发送端 `ref_latent+ref_y` 和RGB哈希、全文件SHA与有序序列校验。每份保存后的FP32 latent再送入原生成器，要求uint8 RGB逐字节相同。

`decode_student_pilot.py`是独立实验入口：读取原码流，只替换P帧RGB生成器；禁止读取原图、缓存latent、缓存教师和掩码。保留全文件载荷SHA、逐帧参考链、有序latent校验和所有I帧RGB校验。学生RGB使用明确的模型标识及独立有序RGB校验，绝不冒充原教师RGB哈希。该脚本没有替换生产编解码入口。

## 在本机复现

数据、权重和大检查点留在工作区 `02_实验数据/优化_GLC蒸馏/pilot_20261029_01`，不提交Git。已有结果不必重跑。新实验必须使用不存在的新目录；以下变量是示例，先将 `$pilotOutput` 改成新目录。

~~~powershell
$pilotRepo = 'C:/Users/lenovo/Documents/ChatGPT/语义通信/01_项目/代码/semantic_video_test'
$pilotStage = "$pilotRepo/12_优化阶段_GLC蒸馏"
$pilotOutput = 'C:/Users/lenovo/Documents/ChatGPT/语义通信/02_实验数据/优化_GLC蒸馏/新的试验目录'
$pilotGpuPython = 'C:/Users/lenovo/Desktop/works/work/semantic-video-training/.venv-glc/Scripts/python.exe'
$pilotCpuPython = 'C:/Users/lenovo/Desktop/works/work/semantic-video-mlvc/.venv/Scripts/python.exe'
$env:PYTHONIOENCODING = 'utf-8'

& $pilotCpuPython -B "$pilotStage/prepare_pilot.py" --output $pilotOutput
if ($LASTEXITCODE -ne 0) { throw '数据准备失败' }
& $pilotGpuPython -B "$pilotStage/cache_pilot.py" --output $pilotOutput --role encode
if ($LASTEXITCODE -ne 0) { throw '编码缓存失败' }
& $pilotGpuPython -B "$pilotStage/cache_pilot.py" --output $pilotOutput --role decode
if ($LASTEXITCODE -ne 0) { throw '独立缓存校验失败' }
& $pilotGpuPython -B "$pilotStage/train_pilot.py" --output $pilotOutput --mode kd
if ($LASTEXITCODE -ne 0) { throw 'KD训练失败' }
& $pilotGpuPython -B "$pilotStage/train_pilot.py" --output $pilotOutput --mode gt
if ($LASTEXITCODE -ne 0) { throw 'GT对照训练失败' }
& $pilotGpuPython -B "$pilotStage/run_pilot_evaluation.py" --output $pilotOutput --plot-python $pilotCpuPython
~~~

CPU环境复用已有numpy/Pillow/pycocotools/matplotlib；GPU环境复用已有GLC/PyTorch/OpenCV。没有安装依赖、修改上游源码或覆盖官方权重。

可在试验根目录创建名为 `STOP` 的文件请求训练保存检查点并停止；删除该文件后，用 `train_pilot.py --mode kd|gt --resume` 恢复。恢复只接收与冻结计划、模式、抽样哈希相符的检查点。发生OOM/断电等意外时从最近一次 `last.pt` 恢复，额外已写日志保留在原文件，恢复写新日志。

## 评价范围

画质报告同时给出全帧、P帧、鱼体GT区域PSNR，RGB SSIM、对教师误差和细节梯度能量比。梯度能量高也可能是噪声，不能单独作为更清晰的证明。帧间误差变化仅为未做运动补偿的诊断代理，不能等价为已消除闪动。

实际解码对比使用同一96帧码流、FP32和同一设备，三轮交替顺序、每个独立进程先预热I/P各一帧。计时涵盖熵解码、原潜变量参考链、RGB生成、CPU传输及校验，排除模型加载、码流磁盘读取、输出写盘与MP4编码。它是完整模型解码核心耗时，不能写成整个通信/网页应用的端到端加速，也不能换算Orin速度。所有慢步骤保留，未关闭其他桌面程序。
