## 接口与复现

GLC 独立解码产出 `decoded_rgb.npy` 或 `decoded_chunks/*.npy`，格式为 RGB、uint8、THWC。分块尾部按 `chunks[].frames` 读取有效帧。显示后处理在解码 RGB 与预览编码之间运行，输出到新目录，与参考和熵解码状态分开。计算指标使用源 RGB 和无损重建，MP4 用于观看。

实验分支为 `codex/glc-temporal-stability`。GLC Python、上游、权重和 FFmpeg 使用既有入口，部署包沿用现有独立收发版本。 [当前交接](../代码/semantic_video_test/交接文档.md) · [复现文件索引](../代码/semantic_video_test/05_资料与索引/会话收束_20261110/文件索引.md) · [运行环境](../运行环境) · [部署包](../../06_部署包/GLC_Windows_流水线_20261102)
