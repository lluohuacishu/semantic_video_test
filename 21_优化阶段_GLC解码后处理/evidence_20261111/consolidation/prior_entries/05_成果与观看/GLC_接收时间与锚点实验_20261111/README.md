# 接收时间与锚点对照

当前 S8I 已由用户认可，辅助文件固定为 8,865 B。以下左右视频左侧均为已认可 S8I，右侧是新实验档；所有视频均为 150 帧、15 FPS、10 秒原速，MP4 仅供观看。

01/02：稀疏锚点 0/64/128，RAFT 24 次；03/04：当前锚点，RAFT 12 次；05/06：稀疏锚点 0/64/128，RAFT 12 次。候选规则只供本轮比较，尚未确认升级。

当前锚点 /12 数值上几乎复现 S8I，接收后处理约 25.8 秒/10 秒片段，比 24 次迭代快约 35.5%，但仍不是实时。I 帧稀疏锚点明显损害珊瑚稳定性，不建议采用。
