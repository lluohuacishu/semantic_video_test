# GLC 解码端纹理稳定性短段测试

2026-11-08。用已校验的 GLC q0 / GOP64 / reset32 FP32 解码 RGB 测试纹理稳定性。三段各 6 秒，从同一上传视频的不同镜头选出。片段及矩形观察区在处理前写入 [plan_p0.json](plan_p0.json)。原始序号和数据集来源可从该计划还原。

| 片段 | 原片时段 | 帧数 / FPS | 重点观察 |
| --- | --- | ---: | --- |
| 礁壁 | 2–8 秒 | 180 / 30 | 礁壁上缘纹理、小鱼和气泡 |
| 斑点鱼 | 13–19 秒 | 180 / 30 | 鱼身斑点、尾鳍、下方珊瑚 |
| 移动礁壁 | 39–45 秒 | 90 / 15 | 视角变化、红珊瑚和经过的鱼 |

每段比较原始 GLC、[第 11 阶段两帧滤波](../11_优化阶段_纹理稳定性/temporal_filter.py)和三帧滤波。三帧版对齐前后各一张未经滤波的邻帧，保留当前帧低频，只在两侧匹配可信且建议的修正方向一致时调整高频。它用两侧较小的修正，权重上限 0.45，RGB 单通道改变量限于 10。运动估计沿用半分辨率 Farnebäck，门控包含前后向误差、低频颜色差、越界和局部光流突变。

## 首轮结果

| 片段 | 珊瑚区时序高频 MAE 原始 | 两帧 | 保守三帧 | 有效掩码覆盖 |
| --- | ---: | ---: | ---: | ---: |
| 礁壁 | 8.997 | 8.481（−5.7%） | 8.805（−2.1%） | 68.6% |
| 斑点鱼 | 11.699 | 10.541（−9.9%） | 11.017（−5.8%） | 约 100% |
| 移动礁壁 | 7.400 | 7.044（−4.8%） | 7.276（−1.7%） | 49.3% |

两帧版在三个片段的珊瑚区时序误差均值和逐帧 P95 都更低。保守三帧版对运动观察区改动较小，RGB 通道平均绝对改变量为 0.21–0.50，两帧版为 0.65–1.38。斑点鱼片段的珊瑚区高频幅度相对源画面从原始 GLC 的 0.761 降至两帧的 0.674 和三帧的 0.717。运动区是人工选定的矩形观察区，像素指标包含背景。

本机 i9-14900HX，OpenCV 4.10 单线程，OpenCL 关闭。两帧滤波均值 48.5–53.5 ms/帧，三帧版 68.4–70.3 ms/帧，均含光流、门控和融合。三帧版每对双向光流复用一次，滤波计时独立于 I/O、评价和预览。三帧需要一帧前瞻。

## 评价与复现

使用同源同尺寸的无损 RGB 计算指标。评估光流及有效掩码只用源 RGB，所有方法在同一掩码上计分。时序指标比较两帧经运动补偿后的灰度高频变化与源画面对应变化的绝对误差。珊瑚区高频幅度、空间误差与运动区 PSNR 一起报告。珊瑚和鱼的观看结论以原速对照为准。

在本机现有 GLC Python 环境中运行，传入配套的 FFmpeg 可执行文件路径和一个新输出目录。

```powershell
python -B -X utf8 '21_优化阶段_GLC解码后处理/run_p0.py' --ffmpeg $glcFfmpeg --output $glcTrialOut
python -B -m unittest discover -v -s '21_优化阶段_GLC解码后处理'
```

脚本按工作区 `01_项目/GLC后处理/接口与基线.json` 定位无损帧，检查既有数据哈希，并使用 `chunks[].frames` 确定分块有效帧。工作区布局不同时可传入 `--workspace`。每段输出两种增强 RGB、逐帧 CSV、完整四宫格 `compare.mp4` 和两倍局部对照 `zoom.mp4`。四格依次为源画面、原始 GLC、两帧、三帧。六个预览都用 FFprobe 核对了帧数、帧率和时长。
