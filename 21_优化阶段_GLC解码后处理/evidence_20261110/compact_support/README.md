# 低码率可靠区证据

本目录只保存配置、实际文件字节、发送/独立接收收据、评分、原速反馈和核验。完整数组、视频与实际两路文件在本机运行目录。

先看 `selected.json`、`final_summary.json`、`visual_review.json` 和 `verification.json`。`video1/evaluation_screen` 保留缩网格的退步结果，不能仅展示选中候选。源代码快照清单在 `source_initial` 和 `source_final`；完整源码随本提交保存。

50,000 B仅为10秒40kbps绝对上限，最终六个候选全部低于各自本体。H.265按两路总字节上限比较，实际包略小，非逐字节相等。
