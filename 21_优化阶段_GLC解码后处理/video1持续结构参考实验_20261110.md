# video1 持续结构参考：23 帧原速小段

**后续已推进到 10 秒与实际辅助文件。** T 获得“整体明显更稳，过渡可接受”的反馈，U 获得“U 与之前的 T 差不多，都比原始 GLC 稳”的明确反馈；基础／辅助各为 25.57／34.23 kbps。见[长段与实际辅助流报告](video1持续结构10秒与实际辅助流_20261110.md)。下文保留短段阶段的设置、结果与当时边界。

2026-11-10。用户确认首轮 C 的晃动明显减轻，但指出中间与外围存在清晰度分界。扩大到可见黄珊瑚的 C2 得到第二次反馈：**“分界改善，整体更稳”**。这是一个开发小段的原速认可，尚不是完整视频或实际双流方案的验收。

## 范围与控制

复用 video1 前 150 帧的 512×288、15 FPS、q0、GOP64/reset32、FP32 独立解码。基础文件 31,963 B，按原 10 秒为 25.570 kbps。主实验取零基 **105–127 帧**，共 23 帧、1.533 秒，22 个相邻帧对；全部是普通 P 帧。固定锚点为第 105 帧，沿用已存在的直接双向源 RAFT，不重新估计运动，也不递归重采样。原始码流、无损 RGB 与参考链不变。

所有新缓存方案都使用原片运动、原片可靠性或手工源图范围，属于**离线辅助诊断**。C/C2 的参考 RGB 来自 GLC；R/R2 另外使用第 105 帧的源 RGB。没有实际封装辅助文件，因此不报“零额外码率”或宣称满足辅助流 40 kbps。

| 组别 | 实际处理 |
| --- | --- |
| 原始 GLC | 已验证的原始独立解码 |
| S | 上一轮每 15 帧更新、增加 G3−G12 结构带的结果，按哈希读取 |
| S＋L | 将 S 的结构带与已有 L 的长锚点组合，保留原固定窗口、0.82 上限和细纹门控 |
| C | 用第 105 帧 GLC 的完整 RGB 结构持续重投影，在可靠内部权重为 1；不周期换回当前 GLC |
| R | 与 C 使用完全相同的运动、范围与权重，仅将锚点换成源 RGB |
| B0 | 在 C 相同修改范围逐帧空间模糊，单一 sigma 匹配 C 的细纹幅度 |
| C2／R2 | 将 C／R 的中部多边形扩大到整块可见黄珊瑚及窄外缘；羽化从 4 像素缩至 2 像素，加入小橙鱼保护 |

首轮多边形仅由原片第 105 帧确定。扩展范围根据用户的外围反馈，查看源帧后另行固定；旧结果未覆盖。鱼保护以源图右上区域的橙色连通域加 7×7 膨胀实现，是本素材启发式掩码，并非通用鱼分割。新露出、原锚点遮挡和配准不可靠处回退到原始 GLC。

## 同一固定黄珊瑚框的结果

所有组在原有固定框 `[342,10,502,105)` 和完全相同的源运动可靠掩码上比较。计分使用相邻源帧 Farnebäck，与渲染的直接锚点 RAFT 分开。数值来自无损 uint8 RGB。粗尺度为高斯 sigma3 亮度，时序误差减去源画面的对应变化；NCC 为运动对齐后的细纹归一化相关性。

| 组别 | 粗尺度时序 MAE ↓ | 细纹跨帧 NCC ↑ | 细纹幅度 | 区域 PSNR ↑ |
| --- | ---: | ---: | ---: | ---: |
| 源 RGB | 0 | 0.972 | 6.515 | — |
| 原始 GLC | 6.975 | 0.189 | 7.586 | 17.063 dB |
| S | 4.898 | 0.409 | 6.519 | 17.828 dB |
| S＋L | 4.623 | 0.437 | 6.468 | 17.869 dB |
| C | 3.120 | 0.787 | 7.546 | 17.070 dB |
| **C2** | **1.415** | **0.923** | **7.449** | **17.060 dB** |
| R2 | 1.382 | 0.907 | 6.331 | 27.551 dB |

S＋L 有小幅改善，但仍受原融合规则限制。C2 稳定了 GLC 既有的纹理与形状，其同帧保真没有明显提升。R2 在相近时序误差下更接近原片，说明“稳定已有结构”和“恢复真实结构”是两个不同的效果。

首轮还在随物体运动的中部多边形内独立计分：原始 GLC／S／S＋L／C 的粗尺度时序误差为 **7.394／6.026／5.793／1.703**；细纹 NCC 为 **0.163／0.266／0.283／0.917**。B0 的细纹幅度与 C 相差约 0.15%，其粗尺度误差仍为 7.379、NCC 为 0.167，支持 C 的效果不只是空间变软。该组数值与上面的固定框是不同区域，不能混用。

## 外围反馈与 C2

- 首轮反馈原文：“C明显减轻，问题是只有一圈清晰啊感觉，外围有点模糊”。
- C2 反馈原文：“分界改善，整体更稳”。
- 每帧平均有效修改面积从 8,835 增至 16,125 像素；完全使用参考的面积从 7,460 增至 15,193 像素。部分混合的像素从 1,375 降至 932。
- 在新增的外围区域内，原始 GLC／旧 C／C2 的粗尺度误差为 **5.351／5.338／2.645**，细纹 NCC 为 **0.219／0.219／0.677**。
- C2 的零权重像素与鱼保护像素均逐位等于原始 GLC，第 105 帧 C2 与 GLC 逐位相同。保护像素相同不等于已证明所有鱼都被正确识别。

视觉反馈来自单名用户、同一短开发段，没有盲测。尚不外推到 10 秒、82 秒或其他素材。

## 编码器／生成器旁路

另补做 video1 全部 150 帧的 `E_video(x) → G_video`，以及仅在 0、64、128 帧换成 I 模型 E/G 的版本。严格加载原角色权重中的对应模块，FP32、TF32 关闭、确定性算法，使用现有 `input_tensor` 的复制填充和归一化。没有调用潜变量压缩、量化、熵编码和帧间预测。第 105 帧重复运行逐位相同。

6 秒后两端都为普通 P 的 55 对中，固定黄珊瑚框粗尺度误差从完整 GLC 的 **5.945** 降至旁路 **4.907**，细纹 NCC 从 **0.311** 到 **0.395**。主实验 23 帧的中部跟踪区域，粗尺度误差仍为 **6.754**，完整 GLC 为 7.394。

旁路仍存在较大时序误差，排除了“只要绕过压缩模块就能稳定”的假设。它不能独自证明生成器、编码器、某一种量化或预测是唯一原因；E/G 来自联合训练权重，该旁路也不是质量上限或可传输压缩器。I/P 切换与固定 P 的普通 P 结果相同，边界数据另保留在逐帧 CSV。

本机旁路加载与推理 26.58 秒，含评价及预览约 40.20 秒，PyTorch 峰值分配约 632 MiB；仅是本次本机运行数据。
