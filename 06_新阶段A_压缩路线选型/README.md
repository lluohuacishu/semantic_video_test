## 3. 必须继承的发现

同预算video91的540p对照中，GLC为108,511 B，H.265为109,515 B，AV1为109,556 B。GLC的DISTS较低，但鱼区PSNR和相邻重建误差变化指标不占优；后者不是经过验证的感知闪烁评分。

新增GLC原生720p点仍是q0／GOP64／reset32：250帧、15 fps、16.67秒、168,338 B。与540p相比，文件增加55.1%，鱼区PSNR约提高0.97 dB；没有证明条纹失真已经解决。这个720p点作为B首次联调的可复现起点，而不是“最优配置”。

SUIM条纹鱼在GLC q63中仍会改变条纹形态，而同一分割器鱼类IoU从原图约0.861变为约0.864。类别区域预测不能替代细节保真、数量、动作和时间连续性判断。三个静态样本不代表整个数据集，q63静态结果也不能当作高q视频结果。
