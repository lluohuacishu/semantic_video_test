## 按顺序执行

在本目录打开 PowerShell。下面路径对应本次保留的原环境；在别处运行需要显式替换。`prepare` 要求输出目录尚不存在，避免覆盖已有结果。

```powershell
$codecProject = 'C:\Users\lenovo\Desktop\works\work\semantic-video-mlvc'
$legacyProject = 'C:\Users\lenovo\Desktop\works\work\semantic-video-training'
$ffmpegExe = 'C:\Users\lenovo\Desktop\works\Python\video-baseline\tools\ffmpeg-9.0.1-essentials_build\bin\ffmpeg.exe'
$pilotRoot = 'C:\Users\lenovo\Documents\ChatGPT\语义通信\work\stage_a_20261017\codec_pilot_repeat'
$pythonExe = Join-Path $codecProject '.venv\Scripts\python.exe'

foreach ($phaseName in @('prepare', 'glc', 'standards', 'evaluate')) {
    & $pythonExe '.\run_pilot.py' $phaseName --project $codecProject --legacy $legacyProject --ffmpeg $ffmpegExe --output $pilotRoot
    if ($LASTEXITCODE -ne 0) { throw "Phase failed: $phaseName" }
}
& $pythonExe '.\make_artifacts.py' --run $pilotRoot --project $codecProject --output '.\evidence_repeat'
```

GLC 两档运行及普通编码器搜索均保存命令、退出码与日志。已经完成的档位可跳过；若某档中途失败，脚本拒绝悄悄覆盖半成品，应查清日志后换新的试验输出位置。不同机器上的耗时不应直接与本次相减当成编码效率结论。

## 各文件的含义

| 文件 | 用途 |
|---|---|
| `试验约定.md` | 先于质量结果确定的输入、参数、预算匹配和评价边界 |
| `run_pilot.py` | 输入准备、GLC 编解码、H.265/AV1 大小匹配、RGB 指标 |
| `make_artifacts.py` | 导出小型指标、校验摘要，以及全部三张 GT 的局部图 |
| `evidence/input_manifest.json` | 50 个源 JPEG、统一 RGB 和输入 PNG 的 SHA-256 |
| `evidence/selection_search.json` | 每个 CRF 候选、字节数和只按大小选点的记录 |
| `evidence/metrics.json` | 六个实测点、逐帧指标、真实文件哈希；评价阶段脚本和 MS-SSIM 源码哈希 |
| `evidence/glc_verification.json` | 两档独立解码、算术配置、模型哈希和源媒体读取检查 |
| `evidence/crop_manifest.json` | 所有 GT 连通区域及固定裁切坐标，没有按好坏筛选目标 |
| `evidence/summary.csv` | 汇总表；传输秒数只按文件负载估算，不含协议开销 |

PSNR 使用全部相应 RGB 像素的平方误差汇总；全局 PSNR 不是逐帧 dB 的算术平均。MS-SSIM 是逐帧三通道计算再平均。鱼区和背景 PSNR 只汇总三张有 GT 的帧，其他 47 帧不被当作“无鱼”。

图中红框来自发布者 GT，四种图使用相同位置。局部显示放大 2 倍，使用最近邻，不是新增图像恢复。概览图仅为阅读而缩小。评价直接使用接收端 PNG，未使用二次编码的预览视频。
