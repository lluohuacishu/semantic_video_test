## 新任务

1. 在“运行新任务”选既有素材或上传本机视频，**手动选择档位**。默认无档位。
2. 可选输出帧数。8 帧用于短功能验证；留空沿用档位默认。支持帧数不超过该档默认，避免意外长矩阵。任意上传视频不保证正好 10 秒；实际尺寸、帧率、帧数与时长在结果中显示，无音频。
3. 点击“① 准备素材”。上传完成只进入 `staged`，不会启动 GPU。
4. 点击“② 开始运行”。单任务队列依次启动发送端与独立接收端；默认 C1 display + C2 native，可显式选择 Python 回退。此首版每端使用新进程，**属于冷态执行**，不把 C2 历史常驻提速当作本次性能。
5. 接收端只取得完整码流的本机副本，不读取源媒体。这里没有网络传输；理论发送时间另列。任务内编解码、排队、服务总耗时、浏览器首次预览加载各自记录，未测网络字段为 `null`。
6. “停止任务”写入停止标记并等待帧/预览边界退出。C2 监督器保留最多 60 秒协作退出窗口，超时只终止本任务持有的进程树。未完成输出不开放成功下载；失败日志保留。
7. 刷新可恢复任务与历史；不自动续跑。服务退出后的未完成任务标记 interrupted，仍存活或不确定的旧 worker 会阻止新任务。任务目录加 OS 文件锁，防止第二服务改写同一队列。

正常停止服务可在其控制台按 Ctrl+C；这会取消尚未完成任务并等待监督器清理。关闭浏览器本身不会终止服务或正在执行的显式任务。不要直接删除任务目录。

## 验证

只运行 C3 单元/HTTP 生命周期测试（不运行神经编码）：

```powershell
& 'C:\Users\lenovo\Desktop\works\work\semantic-video-training\.venv-glc\Scripts\python.exe' -B -m unittest discover -s '.\08_新阶段C_编解码加速与网页展示' -p 'test_c3_web.py' -v
```

`check_c3.py` 只读检查已完成的 8 帧集成任务、C2 参考、源 RGB/重建摘要、FFprobe、工作进程终态、下载副本与测试日志，然后向**新文件**写审计汇总。不会编码，不要为查看已有结果重新跑实验。具体实测任务与证据位置见阶段报告和 `c3_summary_20261020.json`。

浏览器计时由前端 `performance.now()` 回报，是本机功能观测，不是独立性能基准。刷新后没有原始点击起点时，该字段保持 `null`。长时服务稳定性、跨浏览器、跨设备、真实水声与 C4 整轮验收未包含在 C3 结论中。
