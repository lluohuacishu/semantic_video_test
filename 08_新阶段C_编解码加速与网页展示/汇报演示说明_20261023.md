# 低通与语义保护功能说明

2026-10-23：按用户要求，只将已有功能接入原网页。汇报解读页及其导航已移除，D3暂缓。

## 使用

双击[启动汇报演示.cmd](启动汇报演示.cmd)，打开`http://127.0.0.1:8773/`。工作区也有`打开汇报演示.cmd`。接收端为`http://127.0.0.1:8774/`。

1. 从工作区`汇报展示材料/01_可上传视频`选取视频上传，选择处理方法后点“准备文件”。网页已移除“已有素材”和内置示例按钮。
2. 确认输出尺寸、帧率和时间范围；修改后点“更新处理参数”。
3. 点“开始发送”，等待预处理、编码、传输和独立解码完成。
4. 查看原画面、编码输入、接收端重建，可从头一起播放、暂停、下载码流和日志。

| 方法 | 处理 |
|---|---|
| 普通GLC | 原RGB直接编码 |
| 全图低通 | sigma1.2 |
| 全图轻度低通 | sigma0.6 |
| 语义保护：目标原像素 | 预测保护区原像素，背景sigma1.2 |
| 语义保护：目标轻度低通 | 预测保护区sigma0.6，背景sigma1.2 |

语义处理复用现有SUIM SegFormer及D2规则；空预测或单帧保护面积超过一半回退原RGB，结果显示启用/回退帧数。在线不读取GT、不传掩码。独立接收端只读码流。三路播放器使用完成任务的同源预览。

固定q0；链路20/40kbps为传输速度。实际输出码率在结果中显示，不自动配平同片S0或验证10%增幅。PSNR参考处理前采样原RGB。网页沿用INTER_AREA缩放，历史D2使用LANCZOS，功能运行不声称逐像素重现旧实验。
