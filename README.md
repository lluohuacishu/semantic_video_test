# 视频语义通信项目

**2026-10-21：D0 小样本与评价规则已完成，下一步 D1。** 目标是完整传输文件不增大时，让鱼、潜水员更清楚。先用已有 SegFormer、一个背景低通算子和当前 GLC，不以增加模块为目标。已准备 192 帧鱼开发、128 帧留出和 24 张 SUIM，完成标注/真实时间轴核验；独立拍摄来源与潜水员连续视频仍有边界。详见 [D0 报告](09_新阶段D_语义目标增强/D0阶段报告_20261021.md)和 [D 轮入口](09_新阶段D_语义目标增强/README.md)。本次只有 CPU 数据准备，没有 GPU、训练或 GLC 实验。

这里保存项目主要源码、配置、报告与方向总结。当前采用 **GLC-Video**，既有目标为 10 秒视频约 20 秒内发送，编解码处理时间单列；**20–40 kbps** 用作链路预算。A/B 已归档，语义 ROI 等预算净收益未证实，B4 四档保留。C0–C4、C5 本机收尾及独立收发工具已完成；C7 单码流跨卡预览收到 4070 实机通过报告，逐位 RGB、整段画质及真实双机网络仍未验收。详见 [C5 收尾](08_新阶段C_编解码加速与网页展示/C5本机收尾报告_20261020.md)和 [C7 回报审核](08_新阶段C_编解码加速与网页展示/C7补丁4070实机回报审核_20261021.md)。历史资料中的旧 A–F 与新阶段分别记录。
