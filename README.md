# 视频语义通信项目

这里保存项目主要源码、配置、报告与方向总结。当前目标是恢复可观看的视频：允许离线传文件，链路发送速率为 **20–40 kbps**，文件大小和传输时长不限。**2026-10-18 用户已确定采用 GLC-Video，新阶段 A 选型结束；新阶段 B 计划已确定，尚未开始实验。** 旧 A–F 作为历史保留。

当前先读 **[项目状态与接续](当前项目状态与接续.md)**、**[A阶段归档](06_新阶段A_压缩路线选型/README.md)** 和 **[B阶段目标与验收](07_新阶段B_GLC语义保护与传输/README.md)**。B以GLC全画面视频为底座，研究鱼／潜水员区域保护，并接通20／30／40 kbps文件发送与独立重建，不再扩大压缩模型选型矩阵。

[2026-10-18 视频与SUIM试看记录](<06_新阶段A_压缩路线选型/GLC优先验证/用户试看记录_20261017.md>)保留实际连续视频同步四路、鱼纹半速、GLC540p／720p对照，以及三张SUIM的GLC真实单I帧诊断。视频保留本地，仓库存放复现脚本和小型证据；已有负结果不会因路线确定而删除。

上一轮的25个编码点与1,150帧GLC独立解码校验见 **[GLC 第二轮实验报告](<06_新阶段A_压缩路线选型/GLC优先验证/第二轮实验报告.md>)** 和 **[18张结果图](<06_新阶段A_压缩路线选型/GLC优先验证/结果图索引.md>)**。GLC在这些材料上的DISTS更低，但video91鱼区误差较大；感知优势不能替代最终目标保真和时序验收。

前轮单个开发片段的六个真实文件结果保留在 **[初步选型报告](<06_新阶段A_压缩路线选型/A轮结论与后续方向.md>)**。其 H.265 优先建议是历史判断，最终路线以A阶段归档的GLC决策为准。
