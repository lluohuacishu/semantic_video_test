# 视频语义通信项目

这是旧项目的主要源码、配置、报告与方向总结。当前目标是恢复可观看的视频：允许离线传文件，链路发送速率为 **20–40 kbps**，文件大小和传输时长不限。旧 A–F 作为历史保留，后续从**新阶段 A** 开始，目前尚未实施。

仓库按“主要内容”整理，**不包含模型权重、数据集图片、完整视频、逐帧重建结果、虚拟环境和工具二进制**，也不发布大文件附件。报告中的完整归档统计指本地保留的约 4.63 GiB 归档，不代表本仓库大小。仅留本地的链接已在项目文档中标记。

源码保留历史实现，部分启动脚本、模型配置和工具位置仍为原 Windows 绝对路径，尚未完成独立运行所需的环境与路径迁移。本次只整理和上传资料，没有开始新训练或编码实验。
