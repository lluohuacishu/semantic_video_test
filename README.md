# 视频语义通信项目

这里保存项目主要源码、配置、报告与方向总结。当前目标是恢复可观看的视频：允许离线传文件，链路发送速率为 **20–40 kbps**，文件大小和传输时长不限。旧 A–F 作为历史保留；**新阶段 A 继续进行，GLC-Video 为优先主候选**，没有开始新训练。

当前先读 **[GLC 优先验证方案](<06_新阶段A_压缩路线选型/GLC优先验证/README.md>)**。按用户 2026-10-17 的方向更新，优先检验 GLC 在更低文件预算下的观感、目标保真和时序稳定性，保留 H.265 / AV1 对照。当前分支为 `codex/glc-priority-validation`；本次已建立分支和方案，新的低预算试验尚未执行。

前轮单个开发片段的六个真实文件结果保留在 **[初步选型报告](<06_新阶段A_压缩路线选型/A轮结论与后续方向.md>)**。其 H.265 优先建议是当时判断，当前研究优先级以 GLC 专项方案为准。

旧项目整体背景见 **[项目总结与未来方向](<项目总结与未来方向.md>)**。
