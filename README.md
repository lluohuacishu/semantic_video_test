更新：2026-10-31。当前分支`codex/glc-sender-no-rgb`，面向水下AI盒子编码、岸上GPU重建可观看视频，允许离线处理。**Orin实机、能耗和跨设备验证尚未完成。**

## 当前可用入口

本机网页：http://127.0.0.1:8773/inference/ ，外部浏览器可用。桌面双击`GLC_编码加速网页.cmd`，或运行[仓库启动器](16_优化阶段_输入编码器推理加速/打开加速效果对比.cmd)。

支持上传/复用原视频、完整处理至EOF、帧率减半、真实码流大小和平均码率、耗时与重建播放。编码四种模式，解码独立选择原版FP32、TRT FP32/混合精度；默认原版解码，一次编码可复用多种独立解码。见[网页说明](16_优化阶段_输入编码器推理加速/网页使用与完整视频验收_20261031.md)。打开页面不启动GPU任务。
