# 视频语义通信项目

这里保存项目主要源码、配置、报告与方向总结。当前目标是恢复可观看的视频：允许离线传文件，链路发送速率为 **20–40 kbps**，文件大小和传输时长不限。旧 A–F 作为历史保留；**新阶段 A 已完成初步压缩路线选型**，没有开始新训练。

当前先读 **[新 A 轮结论与后续方向](<06_新阶段A_压缩路线选型/A轮结论与后续方向.md>)**：H.265/x265 加语义 ROI 为工程主线，AV1 为强基线，GLC-Video 保留研究分支。该选择基于论文、现有工程和单个开发片段的六个真实文件实测点；独立新场景和动态 ROI 接入仍待验证。

旧项目整体背景见 **[项目总结与未来方向](<项目总结与未来方向.md>)**。
