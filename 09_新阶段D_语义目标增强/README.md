## 最新结果与接续

GT目标轻度低通G比原GT保护O的鱼PSNR提高1.040/0.669 dB，但相对全图低通B仍低1.022/0.571 dB。021 G比B多12 B，满足硬预算但不算严格近等体积。021真实预测P比B/W低0.717/0.154 dB；011预测仍全程回退，复用C。

固定q0下021 P比C提高0.637 dB、文件减少5.95%，说明改善不完全来自提高q，但尚未超过非语义对照。七个视频在工作区`02_实验数据/D_语义目标增强/D22_20261022_r1/viewing/index.html`，包括B/O/G、021 B/C/P、W/G及原图对照。MP4仅为有损观看副本，发送文件仍为glcv。

用户已反馈两片都更喜欢目标原像素的锐利感，认为全图/目标低通较糊；GT/预测标签对应和最终验收仍待确认。见[观看反馈](D22观看反馈与后续方向_20261022.md)。下一步保留目标原像素候选，优先处理011预测保护回退。下一轮尚未开始，不自动扫强度、扩大q、训练或改GLC。
