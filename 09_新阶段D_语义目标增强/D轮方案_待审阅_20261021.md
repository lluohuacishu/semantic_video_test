2026-10-21，v2。**规划修订，未启动模型推理、训练或视频实验。** 用户阅读外部 `D.md` 后表示倾向第二条路线。因此本轮核心改为：**总传输负担不增加，在编码时优先保护鱼、潜水员，让关键目标更清楚且运动稳定。** 原接收端增强方案降为可选辅助，不作为必经阶段。首版规划保存在 Git `38c2219`，调整依据见 [路线评审](D路线调整评审_20261021.md)。

这次转向允许规划语义感知编码及预算控制；不恢复压缩器大选型、极限压缩比搜索或 4070 速度调查。C 轮已合入 `main`，D 轮仍独立在 `codex/glc-d`。

## 1. 核心问题与继承结论

研究问题：**同一素材、时间轴、分辨率和完整传输预算下，语义位置能否帮助编码器保留更有价值的目标信息？** 允许有明确上限的背景质量交换，但不能以漏掉鱼、潜水员变形或背景不可辨认换取表面指标。

B2 的 GLC 基础流为 168,338 B，ROI 增强包为 532,330 B，增至 3.16 倍；用户总体观看改善不明显。预测鱼掩码面积仅 0.1653%，32 帧窗口后的传输矩形平均覆盖 42.41%。这些结果不能证明语义选区无效，也不能证明等预算增益成立。[B2 报告](../07_新阶段B_GLC语义保护与传输/B2首片实验报告_20261018.md)

解码后增强、输入预处理和编码器内部资源分配是不同机制。任何一条失败都不能单独否定其他两条；本轮不把“增强网络先成功”设为目标优先编码的前置条件。

## 3. 路线一层：保持 GLC 与接收端，先验证编码前语义保护

```mermaid
flowchart LR
  X[原始视频] --> S[SegFormer 预测目标]
  S --> M[置信度与时序稳定的保护区]
  X --> P[保护目标和上下文 适度简化背景]
  M --> P
  P --> E[现有 GLC 与全局 q 预算控制]
  E --> B[完整 glcv 文件]
  B --> R[现有独立接收端]
  R --> V[目标画质与原始视频对照]
```

首版只在发送端用预测掩码控制背景纹理简化，掩码无需传给接收端；GLC 权重、熵编码、码流格式和接收端保持当前基线。固定分辨率、帧数、时间轴、GOP 和重置规则，各组允许在同样受限搜索规则内选择全局 `q` 以匹配实际预算。适配实际源视频参数，不固定 25 fps 或统一分辨率。

保护区包含目标、软边界和适量上下文；考虑漏检、小鱼、遮挡和目标进出。置信度不足时扩大保护或退出背景处理，不能把未检出区域自动视为安全背景。掩码变化会造成背景闪烁和额外码率，短时平滑必须与当前帧校正结合，避免拖尾或把已移走的目标留下。记录是否使用未来帧，离线方法不能写成实时在线。

先试一个可解释的背景低通/纹理简化算子，限制少量强度和边界参数。目标 RGB 保留不等于重建目标必然改善：感受野、时间参考和全局 q 都可能影响目标。固定 q 下文件变小只是诊断，必须在实际预算匹配后看目标质量；不能由文件变小直接声称“更多比特分给了鱼”。

代码核对：当前 `NeuralCodec.frame()` 读取头部单个 `q`，I/P 使用该索引；内部先验还有学习到的空间量化参数，**但没有外部语义区域控制接口**。因此第一层只能称为语义引导预处理/间接资源分配。[实际编解码入口](../04_外部依赖快照/semantic-video-training/scripts/glc_video_codec.py)

## 4. 路线二层：语义感知 GLC 适配，空间控制按需升级

第一层用于低成本建立对照与诊断，不是第二层有效性的数学必要条件。若第一层无收益，先分清定位、预处理方式、预算匹配和编码表达能力的问题；只有具体可检验的理由才进入一次小范围编码器适配，不自动扩大模型和训练量。

优先候选为**率失真损失中的目标优先权重与有限编码模块适配**：以原始源图为监督，目标/背景分别按有效像素数归一化，加入边界和必要的时序项，同时保留码率项。比较“普通率失真微调”和“语义加权微调”，两者起点、可训练模块、数据和更新预算一致。训练使用 GT 或开发标注不等于推理可以读取 GT；若编码决策依赖语义条件，正式输入必须是预测结果。

研究表达式可写为 `L = R_est + λt·D_target + λb·D_background + λe·D_boundary + λτ·D_temporal`。它只是拟定目标；`R_est` 需要可微训练路径并用实际完整码流字节校准。当前真实编码入口使用推理模式、整数熵编码及 NumPy 往返，不能直接加一个 loss 就宣称支持反向传播。D3 先审核上游训练代码、冻结范围、I/P 参考展开、显存与可微率估计，再确定实施模块。

仅做加权微调不等于获得可指定“鱼 15 KB、背景 10 KB”的控制器。若需要显式空间量化/增益图，再单独评审编码器、解码器、熵先验及参考状态如何一致重建；涉及量化图或新模型标识时，定义版本和完整字节账本，不能向旧解码器偷偷加入只在发送端知道的状态。新权重单独保存和标识，不能覆盖 C 轮权重或原发布包。

WACV 2023 的方法以全局率失真参数和 ROI 掩码条件化网络，说明区域质量控制有研究依据；它不是当前 GLC 的现成接口。[论文](https://openaccess.thecvf.com/content/WACV2023/html/Fathima_A_Neural_Video_Codec_With_Spatial_Rate-Distortion_Control_WACV_2023_paper.html) ROI-DVC 的官方摘要描述 ROI 感知损失与分区域编码策略；本轮不直接照搬其未核对的实现细节。[IEEE 摘要](https://ieeexplore.ieee.org/document/10647832)

## 5. 总预算与公平比较

**字节口径：** `S_total = 完整 glcv + 必要语义/量化侧信息 + 新增封装或控制元数据`，采用实际落盘/发送字节。预部署固定模型的交付体积单列；若按视频发送权重或模型增量，就计入该次传输。全部组统一协议；网络协议、重传和纠错开销另记，不能声称应用文件字节已覆盖真实水声链路。

20 kbps × 20 秒 ÷ 8 = **50,000 B**，是未扣协议/纠错的理论发送容量；文中的 25 KB 示例对应 20 kbps 发送 10 秒，不能把播放时长与允许发送时间混同。D0 明确应用预算与保留开销后冻结预算点，保留既有“10 秒视频约 20 秒发送”目标，编解码和语义处理时间另计。

同预算上限与等实际体积分别报告：

- 每组实际 `S_total ≤ B`；普通 GLC 也拥有预先固定的有限 q 搜索，不能故意使用不利档位。测试时仅用文件大小选择 q，不能用测试 GT 或画质挑参。
- 主配对要求语义组 `S_sem ≤ S_base`，且 `(S_base-S_sem)/S_base ≤ 2%`，才标注“近等体积且未增加字节”；2% 是建议工程匹配门槛，D0 冻结。只有完全相等才写相同字节数。
- 匹配不到时报告真实大小、预算余量及可实现的质量—字节曲线；不填充假字节、不把插值当实际码流、不因结果不好放宽门槛。无可用点则记录预算不可达。
- 学习到的跨空间/跨帧熵模型通常不能把真实文件字节唯一拆成“鱼占多少、背景占多少”。局部熵估计可以辅助解释，但不是可逐区域精确记账的已证实机制。

最小实际对照：

| 组 | 内容 | 用途 |
|---|---|---|
| A | 原始输入 + 现有 GLC，匹配预算 | 强基线 |
| B | 无语义的纹理处理/固定区域保护 + 同一 GLC | 排除一般平滑或空间选择造成的收益 |
| C | 预测目标保护 + 同一处理算子和 GLC | 语义位置是否帮助目标质量 |
| O | 已知正确掩码 + 同算子和预算 | 离线诊断定位误差，不计作部署成绩或保证性上界 |

B 至少含普通全图处理；增加一个面积/时序相近的固定或移位保护区，检查“保护了正确位置”的作用。选择规则预先冻结，控制不能用测试 GT 挑出最坏位置。C/O 与 A/B 统一预算规则、源帧和独立接收解码。D3 若启动，再另设等训练预算的普通/语义微调对照。

最终素材目标仍为至少 6 段鱼和 3 段潜水员连续片段，约 6–10 秒/段，按真实来源和历史使用情况冻结。素材不足时按实际范围报告，不把鱼结果扩展到潜水员，也不把静态图重复成视频验收。

## 7. 怎么验收“关键目标更清楚”

主结果是隐藏方法名、随机左右的配对观看，先正常尺寸连续播放，再看同位置同倍率裁剪。评价目标可辨认性、真实轮廓/纹理、运动稳定性；同时记录平局、变差、漏检目标、背景信息丢失和处理边界闪烁。尽量有至少 3 位观察者；单人评价明确为探索性，按视频/来源汇总，不能把相邻帧当独立样本。

**参考必须是未经过语义预处理的原始源 RGB。** 不能用简化后的编码输入作为 PSNR 标准；也不能从二次有损 MP4 计算像素质量。固定独立 GT 目标区评价 PSNR/SSIM、局部 LPIPS、边界/背景误差与目标大小分组；时序指标排除遮挡并校正运动，检测/分割分数仅辅助，选区模型不能当唯一裁判。

建议在 D0 冻结的探索性通过条件：C 相比 A 与合理无语义控制具有一致的目标观看收益，多数来源方向一致，无明显新造结构或严重闪烁；背景损失在预登记范围内，总字节不增加。报告盲评人数、平局、实际字节差和不确定性，不把小样本偏好写成统计证明。若目标原本没有可辨细节，不承诺恢复真实纹理。

原接收端复原网络保留为后续可选模块，若启用必须独立报告它增加的效果和任何侧信息成本，不混作编码比特分配的贡献。本轮的正式名称为“语义感知视频编码/通信”，尚不主张只传抽象语义特征或已验证真实水声链路。
