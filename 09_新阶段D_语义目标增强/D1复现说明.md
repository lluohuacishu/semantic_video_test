下面是从权威仓库执行的复现命令，仅供明确需要重建时使用。输出必须使用新目录，不能覆盖本次结果。按用户要求不包含任何数据、权重哈希或 ZIP 完整性重扫。

```powershell
$env:PYTHONUTF8 = '1'
$d1Stage = '09_新阶段D_语义目标增强'
$d1Data = 'C:\Users\lenovo\Documents\ChatGPT\语义通信\02_实验数据\D_语义目标增强'
$d1Corpus = Join-Path $d1Data 'D0_20261021_r1'
$d1Output = Join-Path $d1Data 'D1_reproduce'
$d1SegPython = 'C:\Users\lenovo\Desktop\works\work\semantic-video-training\.venv-segformer\Scripts\python.exe'
$d1EvalPython = 'C:\Users\lenovo\Desktop\works\work\semantic-video-mlvc\.venv\Scripts\python.exe'
$d1FFmpeg = 'C:\Users\lenovo\Desktop\works\Python\video-baseline\tools\ffmpeg-9.0.1-essentials_build\bin\ffmpeg.exe'

& $d1SegPython -u (Join-Path $d1Stage 'infer_d1.py') --inputs (Join-Path $d1Corpus 'd1_development_inputs.json') --output $d1Output
if ($LASTEXITCODE -ne 0) { throw 'D1 inference failed' }
& $d1EvalPython -u (Join-Path $d1Stage 'evaluate_d1.py') --corpus $d1Corpus --run $d1Output
if ($LASTEXITCODE -ne 0) { throw 'D1 evaluation failed' }
& $d1EvalPython -u (Join-Path $d1Stage 'visualize_d1.py') --corpus $d1Corpus --run $d1Output --ffmpeg $d1FFmpeg
if ($LASTEXITCODE -ne 0) { throw 'D1 visualization failed' }
```

PNG bit 缓存保存 FP32 概率直接比较后的二值结果，不保存舍入概率；一个输入只做一次鱼模型和一次潜水员模型推理，三个候选与原阈值诊断复用结果。GT 实例覆盖由原 COCO RLE 计算，不以框或预测连通域替代鱼实例。`d1_protection.py` 不读取 GT。

GPU 环境已有 torch/transformers；CPU 评价环境已有 numpy/Pillow/scipy/pycocotools。本次没有安装新依赖、更新环境或改 C 轮 Teacher。模型类别/状态字典严格加载是运行要求，不是额外完整性扫描。
