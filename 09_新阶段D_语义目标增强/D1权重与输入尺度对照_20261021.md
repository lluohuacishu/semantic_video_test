# D1 后续：底模分块明显改善鱼类覆盖，定位仍未通过

2026-10-21。完成预先登记的两套权重 × 两种输入处理对照。**在相同阈值和保护规则下，SUIM 底模配合原尺寸分块，比既有鱼类适配权重更适合这三段开发鱼素材；整图缩到长边 256 明显降低召回。** 当前最佳诊断组合为 `base_tiles512 + recall_hold1`，三段保护覆盖为 **78.22% / 98.89% / 91.54%**。四组都没有通过原定位门槛，未改正式收发默认配置，未运行 D2。

## 固定范围

同一批 192 帧鱼（001/002/003 各 64 帧）和 24 张 SUIM 静态图；鱼视频原尺寸 1920×1080、30000/1001 fps。原 `adapted_tiles512` 直接复用 D1 输出，其余三组各新增 216 次冻结推理，共 648 次“输入×配置”推理。

- 权重：已有 SUIM 底模与已有鱼类适配权重，不下载或训练新模型。
- 输入：原尺寸 512 分块、步长 384；或者保持比例缩到长边 256 后居中黑色补边。两者输出均恢复到原尺寸。
- 鱼种子固定为 class 6 概率 ≥0.5；潜水员种子复用原 D1 结果，各组完全一致。
- 保护规则固定 `recall_hold1`：鱼/潜水员并集，长边 1920 时外扩 16 像素，保留上一帧原始种子；不递归积累、不读取未来帧，不再扩大边界或搜索阈值。
- 推理只读 RGB；CPU 评价随后读取 GT。007/025 留出序列未推理。没有重扫 ZIP、数据或模型指纹，D0 和首轮 D1 证据不重写。

执行计划：[预登记 2×2 对照](d1_model_comparison_plan_v1.json)。原阈值 0.9/0.7 的二值缓存保留，但本次四组主比较均只用预登记的 0.5。

## 四组结果

下表为**硬保护区覆盖的标注目标像素比例**，不是识别准确率或压缩后画质。覆盖计算不计入整帧回退。三段分别统计，不能用总体均值遮住 001 的失败。

| 鱼权重与输入 | 鱼 001 | 鱼 002 | 鱼 003 | ≥90% 覆盖的实例×帧 | 完全未保护的实例×帧 |
|---|---:|---:|---:|---:|---:|
| 鱼类适配 / 原尺寸分块（原 D1） | 33.85% | 93.44% | 75.36% | 254/454（55.95%） | 119 |
| **SUIM 底模 / 原尺寸分块** | **78.22%** | **98.89%** | **91.54%** | **378/454（83.26%）** | **27** |
| SUIM 底模 / 长边 256 | 54.12% | 61.69% | 57.91% | 218/454（48.02%） | 171 |
| 鱼类适配 / 长边 256 | 23.46% | 49.13% | 30.56% | 105/454（23.13%） | 327 |

454 是实例在各帧出现的计数，并非 454 条独立鱼。底模分块的小鱼（面积 < 画面 0.1%）达到九成覆盖的数量从 **107/228 提高到 189/228**，完全无交集从 **87 降至 20**。

鱼分支自身的像素召回，不含潜水员并集、外扩和历史保留：

| 鱼权重与输入 | 鱼 001 | 鱼 002 | 鱼 003 |
|---|---:|---:|---:|
| 鱼类适配 / 原尺寸分块 | 0.85% | 45.54% | 26.02% |
| **SUIM 底模 / 原尺寸分块** | **36.94%** | **74.22%** | **55.93%** |
| SUIM 底模 / 长边 256 | 13.60% | 4.27% | 13.31% |
| 鱼类适配 / 长边 256 | 0.00% | 0.00% | 0.61% |

同样分块时，更换为底模的原始召回增加 **36.09 / 28.68 / 29.91 个百分点**；同样长边 256 时，底模也高于适配权重。两套权重都在分块下获得更高召回。这支持“既有适配权重与过度缩小输入都与当前漏检有关”，**不能仅凭此判断历史训练过拟合、类别遗忘或损失函数错误**。两种输入同时改变目标尺度、上下文和分块边界，不把差异全归因于某个单独机制。

这也不是原尺寸分块在所有指标上胜出：底模分块的标注相对精确率为 **5.10% / 8.41% / 8.74%**，IoU 为 **4.69% / 8.17% / 8.18%**；底模长边 256 的精确率更高，为 **91.96% / 84.35% / 73.92%**，但漏检多。SFISHTRACK 标注之外可能仍有鱼，不能把所有补集预测都当成确认误检；这些数字仍提醒我们，当前分块保护并不精确。

## 剩余缺口与代价

按执行前的规则，四组都失败时选择“最差鱼片段覆盖最高”的组合，因此选中 **base_tiles512**。它仍只作为诊断候选。

- 001 仍只有 78.22%，003 仍只有 91.54%，未达到逐片 ≥95%；378/454 的实例九成覆盖率 83.26%，未达到 90%。
- 001 的可见轨迹由 30/64 帧完全无保护降至 7/64 帧，最长连续无交集由 14 帧降至 6 帧；003 的小鱼 track 128 仍有连续 9 帧完全未保护。
- 三段鱼平均保护面积为 **8.19% / 8.41% / 9.64%**，所有鱼帧最大 11.39%。这些面积没有触发原鱼类面积门槛，但尚未测量对应的实际文件代价。
- 保护掩码相邻帧 XOR 占画面比例均值为 **0.785% / 0.721% / 0.774%**，原 D1 为 0.631% / 0.664% / 0.771%。覆盖更高不代表掩码变化更少；XOR 同时包含真实运动，不能据此断言视频闪烁变好或变坏。

潜水员分支预测完全复用，但最终保护取鱼与潜水员并集，更换鱼分支仍会改变潜水员保护。**底模分块的潜水员平均图覆盖为 89.23%，16/20 图达到九成；原 D1 为 91.07%、17/20。** 潜水员原始预测本身没有变化，不能把并集指标变化解释为潜水员网络退化。

| 鱼配置 | 潜水员平均图覆盖 | ≥90% 覆盖的图 | SUIM 正例超半幅回退 | 4 张负例平均/最大保护面积 |
|---|---:|---:|---:|---:|
| 鱼类适配 / 分块 | 91.07% | 17/20 | 0 | 0.25% / 0.69% |
| SUIM 底模 / 分块 | 89.23% | 16/20 | 1 | 1.03% / 2.37% |
| SUIM 底模 / 长边 256 | 89.90% | 16/20 | 1 | 1.51% / 6.03% |
| 鱼类适配 / 长边 256 | 90.56% | 17/20 | 1 | 0.06% / 0.25% |

底模分块在一张 SUIM 正例的硬保护面积达到 52.25%，触发停止背景处理；负例另有一张空预测回退。表中覆盖和面积均使用回退前的掩码，不借全帧保留抬高成绩。SUIM 八类混淆矩阵只复用首轮底模结果作为背景资料，**没有声称四种鱼配置分别通过完整八类回归**。
