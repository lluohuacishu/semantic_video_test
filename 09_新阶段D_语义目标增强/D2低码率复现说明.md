# D2 大目标低码率：口径与复现

2026-10-22 用户要求更换鱼占比更大、场景更有差异的视频，并明确选择保留原帧率、允许适当降低分辨率。

## 当前规则

- [D 轮 v3 协议](d_round_protocol_v3.json)覆盖旧 v2 中“30–40 kbps 仅为参考”的规定。完整发送文件必须同时满足 `8*S/T ≤ 40000` 和 `10*S ≤ 11*S0`，两者取更紧上限。
- [本轮计划](d2_lowrate_plan_v1.json)在新编解码前登记。011（文件名 000006–000069）与 021（000353–000416）各 64 帧；真实 PTS 均为 30000/1001 fps，未抽帧。
- 011/021 已转为开发素材。标注筛选过的序列和源图看过的序列不再声称完全未见；007/025 未参与本轮，源独立性仍未证明。
- 先以 q0 测共同分辨率阶梯。640×360 未双双达标，512×288 达标，因此未继续更小档。以该档普通 A@q0 冻结 S0，再生成 B/C。
- 普通 GLC 和全图低通均有相同预算机会，C 尝试不大于两个所选对照。每方法每片最多四个 q；画质不用于选参数。
- 021 的 C@q0 比所选 A/B 大，但仍通过两项用户硬限制。[v2 选择修订](d2_lowrate_amendment_v2.json)在独立解码前记录：不追加编码，只展示现有合规文件的真实大小/画质取舍，明确未配平。
- 011 全部 64 帧触发保护区过大回退，因此其 C 输入与 A 相同；不能把不同 q 的效果归为语义收益。021 正常启用 64 帧。
- 原始数据、权重、模型算法、历史报告保留；不重扫旧数据或模型完整性。新素材的原帧时间对应只为避免错算播放时长。

## 已有结果

运行根目录为工作区 `02_实验数据/D_语义目标增强/D2_lowrate_20261022_r1`。查看 `progress.json`、`postprocess_progress.json` 和 `rate_selection.json`；已有运行禁止重复启动。超限探测文件只作诊断，不作为合规发送文件。

## 新目录复现命令

以下仅用于明确需要复现时，不能重复运行当前结果目录。准备脚本从现有 ZIP 只提取两段 MP4 和选中画面，不做全解包。

```powershell
$env:PYTHONUTF8 = '1'
$dPython = 'C:/Users/lenovo/Desktop/works/work/semantic-video-mlvc/.venv/Scripts/python.exe'
$dStage = '09_新阶段D_语义目标增强'
$dData = 'C:/Users/lenovo/Documents/ChatGPT/语义通信/02_实验数据/D_语义目标增强'
$dRun = "$dData/D2_lowrate_reproduction"
$dFfmpeg = 'C:/Users/lenovo/Desktop/works/Python/video-baseline/tools/ffmpeg-9.0.1-essentials_build/bin/ffmpeg.exe'
& $dPython -u "$dStage/prepare_d2_lowrate.py" --run $dRun --archive "$dData/原始数据/SFISHTRACK.zip" --ffmpeg $dFfmpeg
& $dPython -u "$dStage/run_d2_lowrate.py" --run $dRun --phase probe
# 只有 rate_gate.json.state=passed 才可继续。
& $dPython -u "$dStage/infer_d2_lowrate.py" --run $dRun
& $dPython -u "$dStage/run_d2_lowrate.py" --run $dRun --phase compare
```

原封不动复现本机结果时，compare 会在 021 的 C 不能低于 A/B 字节处停下并保存 `comparison_failure.json`。仅当检查点字节与本轮登记值完全相同，才执行以下修订接收；脚本会拒绝其他结果，不能用它放行任意失败。

```powershell
& $dPython -u "$dStage/decode_d2_lowrate_selected.py" --run $dRun
& $dPython -u "$dStage/finish_d2_lowrate.py" --run $dRun
```

若某次比较本身完成了六点独立解码，则直接执行 finish，不执行修订接收。进程可用运行根目录的 `STOP` 在帧边界停止；中断后不自动覆盖或重跑。接收只读取码流与运行配置，不接收源图或 GT。

输入准备、语义推理和码率匹配均不读取重建画质。主指标对相同缩小输入的鱼 GT 统计，另列恢复到原尺寸的误差，不将低分辨率 PSNR 与旧 1080p 数字直接比较。未训练，未增加留出评价，未据此宣布完整 D 轮完成。
