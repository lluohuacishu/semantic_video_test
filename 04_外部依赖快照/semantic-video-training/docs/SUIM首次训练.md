# SUIM 首次训练记录

日期：2026-09-11。项目：semantic-video-training。

这次已完成本地 SUIM 数据检查、模型训练、独立测试和重建图片保存。使用项目原有的轻量卷积自编码器，从随机权重开始训练，没有使用压缩包内的预训练模型。

## 数据处理

原始 SUIM.zip 为 4.885GiB，整个 ZIP 的 CRC 检查通过。提取了 1635 张原图及对应的合并 RGB 标签，约 1.831GiB。原始压缩包保留，旧模型权重、预计算结果和二值标签副本没有提取。

CRC 仅检查文件损坏，不能证明来源或保证安全。目录、数量和类别表与 [SUIM 官方页面](https://irvlab.cs.umn.edu/resources/suim-dataset)一致。包内 INFO.txt 的 Source 误指向另一个数据集，本项目记录以 SUIM 官方页面为准。实验室的[资源说明](https://irvlab.cs.umn.edu/resources)限定数据用于学术研究。

| 检查发现 | 处理 |
| --- | --- |
| 37 对训练图片与标签尺寸不同 | 原文件保留，从训练和验证名单中排除，不直接拉伸标签 |
| 4 张训练图片与测试图片像素完全相同 | 从训练和验证名单中排除，官方测试集保持完整 |
| 全部数据共有 13 组精确重复图片 | 训练/验证范围内的重复图片整体划分，不跨集合 |
| 85 张标签含非标准纯色像素 | 原始 BMP 不变；另按 RGB 每通道 128 阈值映射到最近的八色顶点 |

两个排除名单没有重叠，共排除 41 对。最终训练 1187 张、验证 297 张、测试 110 张。三个集合之间没有解码 RGB 像素完全相同的图片；测试集自身也没有精确重复，测试标签尺寸均正确。

转换后的标签保存为像素值 0～7 的单通道 PNG，用于后续语义分割。八类依次是背景水体、潜水员、水生植物、沉船与遗迹、机器人与仪器、珊瑚礁与无脊椎动物、鱼与脊椎动物、海床与岩石。

颜色转换不等于重新人工标注。约 1.69% 的标签像素不是八种精确纯色，其中至少一个通道值处于 33～222 的像素约占 0.073%，边界仍可能有噪声。问题名单、原始尺寸和统计见 data/SUIM/preparation_report.json。

固定随机种子为 20260910。划分以图片为单位，完全相同的图片作为一组。数据没有完整的视频/场景来源编号；精确去重无法识别相邻帧、不同裁剪或近似图。因此本次不能证明严格的跨场景泛化，后续视频实验应按原始视频或采集场景划分。

## 训练了什么

模型输入一张 RGB 图片，经编码器变成潜变量，再由解码器重建图片。训练目标是减小输入与重建之间的均方误差 MSE。本次没有使用分割标签，也没有训练鱼、潜水员等类别的识别能力。

~~~text
输入图像       [3, 256, 256]
编码器输出     [32, 32, 32]       浮点潜变量
解码器输出     [3, 256, 256]
~~~

潜变量没有量化和熵编码，尚未定义实际压缩码流。不能把权重文件大小、PNG 文件大小或张量维度比例直接当成通信码率，也不能把这次实验称为完整的语义通信。

| 参数 | 设置 |
| --- | --- |
| 硬件 | RTX 4060 Laptop，8GB 显存 |
| 框架 | PyTorch 2.12.0 + CUDA 12.6 |
| 模型 | ConvAutoencoder，404,963 个可训练参数 |
| 输入 | 等比缩放后中心裁剪为 256×256 RGB |
| 轮数 / 批量大小 | 20 / 8 |
| 优化器 | AdamW，学习率 0.0002，其他项使用 PyTorch 默认值 |
| 训练精度 | CUDA 混合精度 |
| 数据增强 | 未使用，训练和评估均固定中心裁剪 |
| 数据读取 | uint8 裁剪图片缓存在系统内存，避免每轮重复解码 |
| 选模型依据 | 验证集 MSE 最低的轮次 |

训练针对中心裁剪区域，并非整幅 720p/1080p 视频，也没有相邻帧运动建模。

## 结果与含义

| 指标 | 结果 |
| --- | ---: |
| 第 1 轮训练 MSE | 0.042085 |
| 第 20 轮训练 MSE | 0.002900 |
| 第 1 轮验证 MSE | 0.016416 |
| 最佳验证 MSE |  0.002810，第 20 轮 |
| 测试图数量 | 110 |
| 测试平均 PSNR | 28.54dB |
| 测试平均 SSIM | 0.7668 |

训练和验证误差都在下降。测试对照图中，水体颜色和主要目标的大致轮廓可以重建，但潜水员装备、鱼的纹理和珊瑚细节明显变软。它已经能学习真实水下图片，画质仍只是入门基线。

PSNR 是像素误差的对数表达，通常越高越好；SSIM 比较局部结构，越接近 1 越相似。这些指标不能证明语义保留效果。本次没有测分割 mIoU、LPIPS、实际压缩率或视频端到端延迟。

测试使用验证集选出的第 20 轮模型，进行 float32 推理。指标按实际保存的 8-bit RGB PNG 计算，每张图等权平均；SSIM 使用 scikit-image 默认 7×7 窗。这与 H.264 项目中 FFmpeg 的视频/YUV 指标、论文中的 MS-SSIM 口径不同，不能直接比较。

脚本记录的训练及结果写出耗时为 29.555 秒，不含 Python/框架启动和首次图片缓存。PyTorch 峰值已分配张量显存为 78.8MiB；这个数字不包含 CUDA 上下文、驱动、库工作空间等总占用，不能理解为整个程序只占 79MiB 显存。本次说明 8GB 显卡足以完成这个小模型实验，不代表大型神经视频编码模型有同样的开销。

先看 comparison.png 的直观差异，再看 loss.png。per_image.csv 可以帮助理解哪些图难以重建；不要反复针对测试结果调参数，调参应使用验证集。

双击 run_suim_train.cmd 可再次训练，每次默认创建新目录。当前权重用于推理，脚本没有实现断点续训，再运行会从头学习。命令和自有视频用法见项目 README.md。

本次还从保存的 110 对 PNG 重新计算指标，均与逐图 CSV 一致；检查了索引标签配对、数据划分无精确交叉、最佳模型轮次，以及旧的视频帧训练和单场景调试入口。检查报告保存在 runs/suim_workflow_check_20260911-101727-034862/checks.json。
