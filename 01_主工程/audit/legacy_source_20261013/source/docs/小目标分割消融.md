# 小目标分割消融记录

## 问题

当前迁移学习模型是 torchvision 的 LR-ASPP + MobileNetV3-Large。输入边长为 256 时，MobileNetV3 的第 4 个 block 特征约为输入的 1/8，高层特征约为 1/16，LR-ASPP 再把结果上采样回 256。一个在原图中很小的鱼、仪器或珊瑚分支，缩放后可能只剩很少的特征点。

这不是唯一原因。SUIM 还有类别不均衡、目标与背景颜色接近、标注边界粗糙和“水生植物”等类别外观变化大的问题，所以需要把结构、输入分辨率和类别指标分开测试。

## 论文依据

- [HRNet：Deep High-Resolution Representation Learning for Visual Recognition](https://arxiv.org/abs/1908.07919) 在整个网络中保留高分辨率分支，并与低分辨率分支反复交换信息，适合位置和边界敏感的分割任务。
- [DeepLabv3+：Encoder-Decoder with Atrous Separable Convolution](https://arxiv.org/abs/1802.02611) 用编码器取得多尺度上下文，再用低层特征解码细化边界。
- [BiSeNet：Bilateral Segmentation Network for Real-time Semantic Segmentation](https://openaccess.thecvf.com/content_ECCV_2018/html/Changqian_Yu_BiSeNet_Bilateral_Segmentation_ECCV_2018_paper.html) 把小步幅的空间路径和快速下采样的上下文路径分开，再进行特征融合，在保留细节和实时速度之间折中。
- [BiSeNet V2](https://arxiv.org/abs/2004.02147) 进一步把细节分支和语义分支分工，明确指出快速下采样会损失低层细节。

这些工作支持“保留浅层高分辨率特征、同时融合深层上下文”的方向，但它们在 Cityscapes 等数据集上的数字不能直接套到 SUIM。这里采用同一 SUIM 划分做本机消融。

## 实验一：只改变输入分辨率

使用原来的 `lraspp_mobilenet_v3_large_suim_v1` 权重，在测试阶段把输入边长从 256 改成 384，不重新训练。这样可以观察单纯增加输入像素是否能找回小目标。

| 设置 | tiny 像素召回 | small 像素召回 | 整体 mIoU |
| --- | ---: | ---: | ---: |
| 256 | 8.6% | 29.4% | 62.65% |
| 384 | 22.8% | 37.7% | 62.65% |

这里的 tiny 是目标面积不超过该图有效像素的 0.1%，small 是 0.1%～1%。召回只统计标注连通区域内被预测为同类的像素，因此比背景占主导的像素准确率更能反映小目标是否消失。384 输入对 tiny 有明显帮助，但整体 mIoU 没有稳定上升，说明分辨率只是瓶颈的一部分。

## 实验二：1/4、1/8、1/16 三尺度融合

新增 `lraspp-fpn` 模型：

1. MobileNetV3 主干继续使用官方预训练特征；
2. 同时取第 3 个 block 的 1/4 特征、第 4 个 block 的 1/8 特征和末端 1/16 特征；
3. 先把 1/16 上采样到 1/8，再与 1/8 特征融合；
4. 再上采样到 1/4，与浅层特征融合，经过轻量卷积后输出类别图。

训练命令与结果目录：

~~~bat
python scripts\train_segmentation.py --model lraspp-fpn --pretrained checkpoints\pretrained\lraspp_mobilenet_v3_large-d234d4ea.pth --balanced-sampling --augmentation strong --epochs 60 --patience 15 --batch-size 8 --size 256 --device cuda --cache-images --output-dir runs\suim_transfer_fpn_20260912
~~~

在本机 RTX 4060 上，验证集最高 mIoU 为 61.64%，固定测试集 mIoU 为 59.20%。与原模型相比，测试集目标统计如下：

| 设置 | tiny 像素召回 | small 像素召回 | tiny 达到 50% 召回的目标比例 | small 达到 50% 召回的目标比例 |
| --- | ---: | ---: | ---: | ---: |
| 原 LR-ASPP | 8.6% | 29.4% | 12.1% | 27.0% |
| 三尺度 FPN | 31.3% | 40.3% | 28.8% | 39.1% |

FPN 明显改善了小目标保留，但整体测试 mIoU 反而下降。逐类结果显示，珊瑚礁、鱼类和小型目标的召回改善较明显，水生植物和机器人类别仍然偏弱。因此不能只看一个总 mIoU 就判断结构成功或失败；当前结论是“多尺度融合对小目标有效，但需要配合类别级训练策略”。

为了避免用测试集选模型，又在验证集上做了同样统计。原模型到 FPN 的 tiny 像素召回为 `9.3% -> 25.8%`，small 为 `35.0% -> 47.8%`；验证集 mIoU 为 `59.67% -> 61.64%`。这三项指标方向一致，说明 FPN 的小目标改善不是只在测试集上的偶然现象。

## 当前结论与下一步

目前可以向导师报告：

> 我们先固定 SUIM 数据和原模型，验证了下采样与输入缩放对小目标的影响。256 改 384 后，tiny 目标召回由 8.6% 提升到 22.8%；进一步加入 1/4、1/8、1/16 三尺度融合后，tiny 和 small 召回分别达到 31.3% 和 40.3%，但总 mIoU 下降，说明多尺度结构改善了细节保留，却引入了类别权衡问题。下一步会在验证集上做小目标裁剪采样、类别损失和边界损失的对照，再决定最终模型。

建议的后续实验顺序：

1. 对 FPN 版本加入目标裁剪或随机高分辨率 patch，避免训练时小目标只占几个像素；
2. 单独提高水生植物、机器人等弱类别的采样和损失权重；
3. 增加边界 F1、每类小目标召回和视频帧间稳定性；
4. 只有在验证集确定收益后，才把候选权重接入演示界面。
